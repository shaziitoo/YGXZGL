# 员工薪资信息管理系统

一个基于 Python 的控制台版员工薪资信息管理系统，使用纯标准库实现，无任何第三方依赖，适合作为 Python 入门练习 / 课程设计项目。


## 功能特性

| 序号 | 功能     | 说明                           |
| -- | ------ | ---------------------------- |
| 1  | 录入员工信息 | 依次输入 ID、姓名、提成、奖金、基本工资，支持连续录入 |
| 2  | 查找员工信息 | 支持按 ID 或按姓名查询                |
| 3  | 删除员工信息 | 按 ID 删除指定员工记录                |
| 4  | 修改员工信息 | 按 ID 定位员工后修改其信息              |
| 5  | 员工排序   | 支持升序 / 降序，可按提成、奖金、基本工资或总薪资排序 |
| 6  | 统计总人数  | 统计当前已录入的员工数量                 |
| 7  | 显示所有员工 | 以表格形式打印全部员工信息及总薪资            |
| 0  | 退出程序   | 确认后退出系统                      |

## 环境要求

- Python 3.6 及以上（开发环境为 Python 3.13.2）
- 无第三方依赖，无需 `pip install`

## 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/<your-name>/<repo-name>.git
cd <repo-name>

# 2. 运行（需在项目根目录下执行，程序会在当前目录读写数据文件）
python sztpython.py
```

Windows 下若 `python` 命令不可用，也可以使用：

```bash
py sztpython.py
```

## 使用说明

程序启动后显示主菜单，输入对应数字进入功能：

```text
==================员工薪资信息管理系统==============
===============功能菜单==================
			1. 录入员工信息
			2. 查找员工信息
			3. 删除员工信息
			4. 修改员工信息
			5. 对员工进行排序
			6. 统计员工总人数
			7. 显示所有员工信息
			0. 退出程序
======================================
请选择功能
```

运行效果示例（录入两名员工后执行“显示所有员工”）：

```text
  ID  	     姓名     	   提成   	    奖金    	    工资    	  总薪资
 1001 	     张三     	  1000  	   1000   	   3000   	  5000
 1002 	     李四     	  800   	   800    	   2500   	  4100
```

## 数据存储

- 所有数据保存在脚本同目录下的 `employee.txt` 中，首次录入时自动创建。
- 文件为纯文本，每行一条记录，内容为 Python 字典的字符串形式，方便直接查看：

```text
{'id': '1001', 'name': '张三', 'ticheng': 1000, 'bonus': 500, 'wage': 3000}
{'id': '1002', 'name': '李四', 'ticheng': 800, 'bonus': 1200, 'wage': 2500}
```

## 项目结构

```text
.
├── sztpython.py    # 主程序：菜单、增删改查、排序、统计、文件读写
├── employee.txt    # 运行时生成的数据文件（可选提交 / 可忽略）
└── README.md
```

`sztpython.py` 内部按功能拆分为多个函数：

| 函数                | 职责            |
| ----------------- | ------------- |
| `main()`          | 主循环，显示菜单并分发功能 |
| `menu()`          | 打印功能菜单        |
| `insert()`        | 录入员工信息        |
| `save(lst)`       | 将记录追加写入数据文件   |
| `search()`        | 按 ID / 姓名查询   |
| `show_query(lst)` | 以表格形式输出查询结果   |
| `delete()`        | 按 ID 删除记录     |
| `modify()`        | 按 ID 修改记录     |
| `sort()`          | 排序并展示结果       |
| `total()`         | 统计员工总人数       |
| `show()`          | 显示全部员工信息      |
